# Multimodal-Brain-Tumor-Segmentation-via-VLMs-on-BraTS-2020
Multimodal brain tumor segmentation using FLAIR MRI + radiology reports. Combines a ResNet-34 Attention U-Net with CLIP-based cross-attention and FiLM conditioning to fuse image and text features. Achieves Dice 0.8589 on BraTS 2020 — within 3.4% of the 3D multi-modal SOTA using only 2D FLAIR slices and text.
